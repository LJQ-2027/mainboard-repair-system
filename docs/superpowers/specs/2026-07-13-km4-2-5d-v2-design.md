# KM4/F151 Repair-Grade 2.5D V2 Design

## Objective

Replace the current debug geometry view with a repair-grade 2.5D board surface. The model must help a technician locate and select source-backed components; it must not imply manufacturing-CAD precision that the supplied material does not contain.

## Product Baseline

The default model view is an orthographic, near-top-down engineering view. It preserves the point map's normalized coordinate system and lets the technician zoom, rotate in-plane, and apply a limited tilt. Reset always returns to a readable top-down board overview.

The model has four visual layers:

1. An exact source-derived PCB silhouette and thin board substrate.
2. A high-resolution point-map engineering surface clipped to that silhouette.
3. Low-profile package bodies for high-confidence footprints only.
4. Selectable reviewed entities, test points, and source-backed highlights.

Medium-confidence footprints remain flat package or pad outlines. Low-confidence footprints are absent from the physical layer. This keeps uncertainty visible and prevents provisional PDF relationships from becoming false 3D facts.

## Package System

Package rendering is driven by a reusable profile catalog rather than arbitrary per-entity height multipliers. The initial catalog covers IC/BGA, passive chip, inductor, crystal, connector, diode/transistor, antenna/metal contact, LED, and test point. Profiles define shape, capped dimensions, height, material family, edge treatment, and whether the package may be elevated at each confidence level.

The browser implementation uses procedural package meshes for the first baseline. The profile interface is intentionally asset-ready: a later Blender-authored GLB can replace a procedural profile without changing board data or technician interactions. Blender is the offline package-authoring layer, not a per-board manual reconstruction workflow.

## Selection And Evidence

Only the seven reviewed entities are primary click targets in this iteration. Selecting one uses a restrained emissive outline and local halo instead of replacing the whole component with a solid yellow block. Existing point-map, schematic evidence, repair guidance, and entity-list synchronization remain unchanged.

The model includes a compact legend for source confidence and a view control for top-down versus inspection angle. No engineering-confirmation or manual-calibration step is added.

## Accuracy Boundary

The supplied point map, schematic, repair guide, and service-manual images are sufficient for normalized location, package-family approximation, source evidence, and a repair-grade 2.5D coordinate surface. They are not sufficient for exact package part numbers, true component height, solder-joint geometry, hidden routing, or photorealistic material reproduction.

No medium-confidence footprint may be elevated. Heights use conservative package-family defaults and are explicitly visual profiles, not measurements. A future physical-board photo or native PCB/Placement/BOM package may refine appearance without changing the normalized board identity model.

## Acceptance Criteria

- Reset opens in a fitted orthographic top-down view with the complete board visible.
- No component is visually taller than a plausible connector or shield-scale structure.
- The point-map engineering layer remains legible enough to convey board density and source structure.
- High-confidence components are elevated; medium-confidence components are visibly flat; low-confidence components are excluded.
- Reviewed entities remain selectable and synchronized with all evidence panels.
- Rotation, limited tilt, zoom, reset, and inspection-angle controls work without resizing the layout.
- Desktop and mobile routes have no overlap, clipping, blank WebGL canvas, or runtime errors.
