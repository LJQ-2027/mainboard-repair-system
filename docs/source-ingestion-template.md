# 资料入库登记模板

## 1. 使用场景

当收到一份来自技术支持、中方技术人员、制造中心或海外现场的文件时，先用本模板完成登记、归类和初步拆解。

本模板的目标不是保存文件本身，而是判断：

- 这份资料属于哪类知识；
- 能抽取出哪些结构化内容；
- 可以进入哪些知识库；
- 还缺哪些字段；
- 下一步应该人工补充、拆成 SOP，还是作为参考资料保留。

## 2. 单文件登记表

| 字段 | 填写说明 |
|---|---|
| file_id | 文件编号，例如 SRC-0001 |
| file_name | 原始文件名 |
| file_type | Word / Excel / PDF / 图片 / 视频 / Log / 其他 |
| source_owner | 来源人员或部门 |
| received_date | 收到日期 |
| language | 中文 / 英文 / 法语 / 阿语 / 其他 |
| main_category | 主分类，见第 3 节 |
| secondary_categories | 可拆分进入的其他库 |
| related_models | 关联机型 |
| related_faults | 关联故障 |
| related_components | 关联器件或点位 |
| related_tools | 关联工具 |
| summary | 文件内容摘要 |
| extractable_items | 可以抽取的结构化内容 |
| missing_fields | 缺失字段 |
| suggested_action | 下一步处理建议 |
| target_knowledge_base | 目标知识库 |
| processing_status | 待处理 / 已归类 / 已抽取 / 已入库 / 暂存参考 |
| notes | 备注 |

## 3. 分类规则

### 3.1 机型资料库

适用文件：

- 原理图；
- 位号图、BoardView、Layout；
- BOM；
- 维修指导书；
- 机型资料包；
- 主板版本说明。

识别关键词：

- 原理图、schematic、SCH；
- 位号图、BoardView、layout；
- BOM、物料清单；
- 主板版本、PCB、PCBA；
- 维修指导书、repair guide。

应抽取字段：

- 机型；
- 主板版本；
- 文件类型；
- 文件名称；
- 关联资料链接；
- 缺失资料项。

### 3.2 故障知识库

适用文件：

- 某类故障分析文档；
- 常见故障汇总；
- 维修经验总结；
- FA 结论摘要；
- 技术支持问题清单。

识别关键词：

- 不开机、不充电、无服务、无显示、显示异常、音频异常；
- 常见原因、排查思路、分析方法；
- 根因、失效模式、现象描述。

应抽取字段：

- 故障现象；
- 别名和关键词；
- 常见原因；
- 推荐检查模块；
- 推荐检查器件；
- 推荐检查点位；
- 初步判断方法；
- 可执行动作；
- 升级或换板边界。

### 3.3 器件与点位库

适用文件：

- 位号表；
- 关键器件清单；
- 测试点清单；
- 正常电压、阻值、电流范围；
- 模块电路说明。

识别关键词：

- 位号、测试点、TP；
- U/C/R/L/J 开头器件编号；
- 电压、阻值、电流、rail；
- 电源、充电、射频、音频、显示、摄像头。

应抽取字段：

- 机型；
- 功能模块；
- 位号；
- 器件名称；
- 器件类型；
- 正常值；
- 检测工具；
- 关联故障；
- 常见维修动作。

### 3.4 诊断 SOP 库

适用文件：

- 标准维修流程；
- 排查步骤；
- 作业指导书；
- 修后验证要求；
- 故障树。

识别关键词：

- 步骤、Step；
- 测量、检查、更换、验证；
- 正常范围、异常判断；
- 下一步、分支、流程；
- 修后验证、复测。

应抽取字段：

- SOP 标题；
- 适用机型；
- 适用故障；
- 所需工具；
- 前置条件；
- 步骤；
- 测试点；
- 正常范围；
- 异常判断；
- 下一步分支；
- 修后验证。

### 3.5 维修案例库

适用文件：

- 单台维修记录；
- 返修记录；
- 中方技术人员案例总结；
- 海外现场案例反馈；
- 带图片、Log、测试数据的维修记录。

识别关键词：

- 案例、维修记录、返修；
- 故障现象、定位过程、维修动作、结果；
- 更换、补焊、清洁、飞线；
- 修复、未修复、二返。

应抽取字段：

- 国家/区域；
- 机型；
- 故障现象；
- 用户描述；
- 初测结果；
- 测试数据；
- 定位过程；
- 损坏器件；
- 维修动作；
- 修后验证；
- 经验总结；
- 是否可转 SOP。

### 3.6 维修边界库

适用文件：

- L4 能力范围；
- 禁修范围；
- 换板条件；
- 工具门槛；
- 技能等级说明。

识别关键词：

- L4、维修等级、能力要求；
- 禁修、换板、升级；
- 工具要求、技能要求；
- 高风险、复杂维修。

应抽取字段：

- 适用机型或故障；
- 本地可处理范围；
- 中方技术人员处理范围；
- 建议换板条件；
- 不建议执行动作；
- 工具要求；
- 技能等级。

### 3.7 培训资料库

适用文件：

- 培训课件；
- 培训标准；
- 考核标准；
- 工具使用说明；
- 新员工学习资料。

识别关键词：

- 培训、考核、课程；
- 工具使用；
- 学习目标；
- 通过标准；
- 维修等级。

应抽取字段：

- 培训主题；
- 适用对象；
- 关联机型；
- 关联故障；
- 所需工具；
- 培训材料；
- 练习样板；
- 考核标准；
- 通过条件。

### 3.8 缺口与需求库

适用文件：

- 问题清单；
- 资料缺失清单；
- 会议纪要；
- 向制造中心或技术支持提出的需求。

识别关键词：

- 缺少、待补充、需确认；
- 原理图、点位图、SOP、测试点、正常值；
- 需要制造中心、需要技术支持。

应抽取字段：

- 关联机型；
- 关联故障；
- 缺口类型；
- 缺口描述；
- 需要谁提供；
- 优先级；
- 下一步动作。

## 4. 文件处理输出格式

每处理一个文件，输出以下结构：

```text
文件：<file_name>

主分类：
<main_category>

可拆分进入：
- <secondary_category_1>
- <secondary_category_2>

内容摘要：
<summary>

可抽取字段：
- <field>: <value>

建议入库位置：
- <target_knowledge_base>

缺失字段：
- <missing_field>

下一步建议：
<suggested_action>
```

## 5. 处理原则

- 一个文件可以进入多个知识库；
- 培训资料通常可以拆出培训库、维修边界库和 SOP 草案；
- 维修指导书通常可以拆出机型资料、SOP 和故障知识；
- 维修案例如果包含完整定位过程，应优先进入案例库，再反哺 SOP；
- 只有文件链接而没有结构化内容时，先进入机型资料库或培训资料库；
- 发现缺失机型、故障、测试点、正常值、案例等信息时，同步生成缺口项。
